# アークナイツ ダメージ計算 参照メモ

## 目的

このファイルは、ChatGPT / Codex がアークナイツダメージ計算アプリを実装・修正するときに参照するための仕様メモである。

目的は「今すぐ作る最小実装」ではなく、最終的にスキル、素質、バフ、デバフ、DPS、総ダメージまで扱える形を見据えて、計算順序と用語を整理すること。

元資料は検証ベースの情報を整理したものであり、公式仕様書ではない。実装時はこのファイルを基本方針として使い、個別オペレーターや例外挙動は必要になった時点で追加検証する。

## 基本方針

ダメージ計算は、次の順序で考える。

```text
1. 攻撃側のステータスを計算する
2. 防御側のステータスを計算する
3. 攻撃倍率を適用し、ダメージ計算用の最終攻撃力を得る
4. 防御力無視・術耐性無視などを適用する
5. ダメージ種別ごとの基礎ダメージを計算する
6. 最低保証ダメージと比較する
7. ダメージ増減効果を適用する
8. 固定値軽減やダメージ置き換えを処理する
9. 回避、無効化、シールド、バリアなどを処理する
10. HP、元素損傷ゲージ、弾薬、SPなどに反映する
```

コードでは、最終的に以下の責務を分けると扱いやすい。

| 責務 | 例 |
|---|---|
| ステータス計算 | 攻撃力、防御力、術耐性、最大HP、攻撃速度 |
| ダメージ本体 | 物理、術、確定、元素ダメージ、元素損傷 |
| 補正処理 | 脆弱、加護、被ダメージ増減、固定値軽減 |
| 防御処理 | 回避、無効化、シールド、バリア |
| 時間処理 | 攻撃間隔、DPS、持続時間、弾薬、ヒット数 |
| 個別効果 | スキル、素質、モジュール、敵特性 |

## ダメージ・回復の種別

| 種別 | 対象 | 概要 | 主な軽減・参照値 |
|---|---|---|---|
| 物理ダメージ | HP | 通常攻撃の多くで使う基本ダメージ | 防御力 |
| 術ダメージ | HP | 術師、補助、術剣士などが扱うダメージ | 術耐性 |
| 確定ダメージ | HP | 防御力・術耐性の影響を受けないダメージ | 原則なし |
| 元素ダメージ | HP | 元素耐性で軽減されるHPダメージ | 元素耐性 |
| HP減少 | HP | ダメージ増減や回避の影響を受けないHP変動 | 原則なし |
| 元素損傷 | 専用ゲージ | 神経損傷、侵食損傷、灼熱損傷、壊死損傷など | 損傷耐性 |
| 治療 | HP回復 | 医療などの通常回復 | 治療効果増減 |
| 回復効果 | HP回復 | リジェネ系。治療とは別扱い | 回復効果増減 |

注意:

- 元素損傷はHPを直接削らず、専用ゲージへ蓄積する。
- 元素損傷が一定値に達すると爆発効果が発生し、その結果としてHPダメージやデバフが発生する。
- HP減少は通常のダメージとは別扱いで、回避や被ダメージ増減の影響を受けない。
- 治療と回復効果は別物。治療不可の味方にも回復効果は入る場合がある。

## ステータス計算の基本枠

攻撃力、防御力、最大HPなどのステータスは、基本的に以下の4枠で考える。

```text
最終値 = [(基礎値 + A合計) * (1 + B合計) + C合計] * D乗算
```

| 枠 | 意味 | 重複時の扱い | 例 |
|---|---|---|---|
| A | 直接加算項 | 加算 | 攻撃力+100、防御力-200 |
| B | 直接乗算項 | 合計してから乗算 | 攻撃力+50%、防御力+100% |
| C | 最終加算項 | 加算 | 鼓舞、奪取 |
| D | 最終乗算項 | 個別に乗算 | 防御力-30%、術耐性-40% |

割合デバフは、単純に足し算しない。

```text
防御力-30% と 防御力-20% が同時にある場合

最終倍率 = (1 - 0.30) * (1 - 0.20)
         = 0.70 * 0.80
         = 0.56
```

この場合、合計で -50% ではなく、最終的に防御力は 56% になる。

## 基礎値の扱い

基礎値は、原則として人事画面や敵データで確認できるステータスを基準にする。

基礎値に含めるもの:

- レベル・昇進段階によるステータス
- 潜在能力
- 信頼度
- モジュール装備によるステータス加算
- ステージや契約などによるルーン系補正

基礎値に含めないもの:

- 戦闘開始後に発動する素質
- 配置後に付与されるバフ
- スキル中のステータス変化
- 鼓舞、奪取
- 敵へのデバフ

ルーン系補正は、通常のバフ・デバフより前に処理され、基礎値が置き換わるものとして扱う。

## 最終攻撃力

攻撃力は、ステータスとしての攻撃力と、ダメージ計算時だけ使う攻撃倍率を分けて考える。

```text
ステータス攻撃力 = [(基礎攻撃力 + A) * (1 + B合計) + C] * D乗算
最終攻撃力 = ステータス攻撃力 * 攻撃倍率E
```

| 表現 | 扱い |
|---|---|
| 攻撃力+n | A枠またはC枠 |
| 攻撃力+n% | B枠 |
| 攻撃力-n% | D枠 |
| 攻撃力のn%のダメージ | 攻撃倍率E |
| 攻撃力がn%まで上昇 | 攻撃倍率Eとして扱う場合がある |

重要:

- 「攻撃力+50%」と「攻撃力の150%のダメージ」は別物。
- 前者はステータス攻撃力を変える。
- 後者はダメージ計算時にだけ倍率として扱う。
- 攻撃倍率Eは対象ごとに変わる場合がある。

例:

```text
基礎攻撃力 = 100
攻撃力+50% = B枠
攻撃力の200%のダメージ = E枠

ステータス攻撃力 = 100 * (1 + 0.50) = 150
最終攻撃力 = 150 * 2.00 = 300
```

## 最終防御力

防御力は物理ダメージを固定値で減らす。

```text
ステータス防御力 = [(基礎防御力 + A) * (1 + B合計) + C] * D乗算
最終防御力 = max((ステータス防御力 - 防御力無視値F) * (1 - 防御力無視割合G), 0)
```

| 表現 | 扱い |
|---|---|
| 防御力+n | A枠またはC枠 |
| 防御力-n | A枠またはC枠 |
| 防御力+n% | B枠 |
| 防御力-n% | D枠 |
| 防御力をn無視 | F枠 |
| 防御力をn%無視 | G枠 |

防御力無視は、ステータス防御力を計算した後に適用する。

## 最終術耐性

術耐性は術ダメージを割合で軽減する。

```text
ステータス術耐性 = [(基礎術耐性 + A) * (1 + B合計)] * D乗算
最終術耐性 = clamp((ステータス術耐性 - 術耐性無視値F) * (1 - 術耐性無視割合G), 0, 100)
```

| 表現 | 扱い |
|---|---|
| 術耐性+n | A枠 |
| 術耐性-n | A枠 |
| 術耐性+n% | B枠 |
| 術耐性-n% | D枠 |
| 術耐性をn無視 | F枠 |
| 術耐性をn%無視 | G枠 |

術耐性は最終的に 0 から 100 の範囲に収める。

## 最低保証ダメージ

物理・術・元素ダメージ・元素損傷には、原則として攻撃側の最終攻撃力の5%が最低保証として設定される。

```text
最低保証ダメージ = 最終攻撃力 * 0.05
```

最低保証は、基礎ダメージと比較して高い方を採用するための下限である。

```text
補正前ダメージ = max(基礎ダメージ, 最低保証ダメージ)
```

注意:

- 脆弱や加護などのダメージ増減は、最低保証を選んだ後に適用する。
- 「必ず攻撃力のn%以上のダメージを与える」効果がある場合は、通常の5%保証ではなく個別効果を使う。
- 確定ダメージは防御側ステータスを参照しないため、通常の最低保証比較は不要。

## 物理ダメージ

```text
基礎物理ダメージ = 最終攻撃力 - 最終防御力
補正前物理ダメージ = max(基礎物理ダメージ, 最低保証ダメージ)
最終物理ダメージ = 補正前物理ダメージ * ダメージ倍率J - 固定値軽減
```

DPS:

```text
物理DPS =
  最終物理ダメージ
  * 通常攻撃1回あたりのヒット数
  / 最終攻撃間隔
```

物理は防御力で固定値減算されるため、同じ総倍率でも多段ヒットは高防御の敵に弱くなりやすい。

## 術ダメージ

```text
基礎術ダメージ = (最終攻撃力 + ダメージ加算H) * (100 - 最終術耐性) / 100
補正前術ダメージ = max(基礎術ダメージ, 最低保証ダメージ)
最終術ダメージ = 補正前術ダメージ * ダメージ倍率J - 固定値軽減
```

DPS:

```text
術DPS =
  最終術ダメージ
  * 通常攻撃1回あたりのヒット数
  / 最終攻撃間隔
```

術は術耐性で割合軽減されるため、単発でも多段でも、同じ総倍率なら防御計算上の不利は物理より小さい。

## 確定ダメージ

```text
補正前確定ダメージ = 最終攻撃力
最終確定ダメージ = 補正前確定ダメージ * ダメージ倍率J - 固定値軽減
```

確定ダメージは、防御力・術耐性・元素耐性・損傷耐性の影響を受けない。

ただし、属性を指定しない被ダメージ増減や、確定ダメージを名指しする効果は適用される場合がある。

## 元素ダメージ

元素ダメージはHPを直接削るダメージで、元素耐性によって割合軽減される。

```text
基礎元素ダメージ = 最終攻撃力 * (100 - 最終元素耐性) / 100
補正前元素ダメージ = max(基礎元素ダメージ, 最低保証ダメージ)
最終元素ダメージ = 補正前元素ダメージ * ダメージ倍率J
```

多くの敵は元素耐性が0のため、実用上は疑似的な確定ダメージのように見える場合がある。

## 元素損傷

元素損傷はHPではなく、神経損傷・侵食損傷・灼熱損傷・壊死損傷などの専用ゲージに蓄積する。

```text
基礎元素損傷 = 最終攻撃力 * (100 - 最終損傷耐性) / 100
補正前元素損傷 = max(基礎元素損傷, 最低保証ダメージ)
最終元素損傷 = 補正前元素損傷 * 損傷倍率J
```

注意:

- 元素損傷はHPダメージではない。
- 爆発効果中は、基本的に新たな元素損傷を蓄積できない。
- 元素損傷の蓄積量は防御力・術耐性・元素耐性の影響を受けない。
- 損傷耐性の影響を受ける。

## HP減少

HP減少は通常のダメージとは別扱い。

```text
HP = HP - HP減少量
```

HP減少は、原則として以下の影響を受けない。

- 防御力
- 術耐性
- ダメージ増減
- 回避
- シールド
- バリア

スルトS3の自傷、特定敵の自壊、ステージギミックなどは、確定ダメージかHP減少のどちらかに分類して管理する。

## 治療と回復効果

治療:

```text
治療量 = 最終攻撃力 * 治療倍率
最終治療量 = 治療量 * 治療効果倍率
```

回復効果:

```text
回復量 = 固定値または効果ごとの計算式
```

注意:

- 治療は医療オペレーターなどの通常回復。
- 回復効果はいわゆるリジェネ。
- 治療不可の味方でも、回復効果は受けられる場合がある。
- 治療効果増減と回復効果増減は別枠として扱う。

## ダメージ増減効果

脆弱、加護、被ダメージ増加、被ダメージ軽減などは、基礎ダメージと最低保証を比較した後に適用する。

```text
最終ダメージ = max(基礎ダメージ, 最低保証ダメージ) * ダメージ倍率J
```

固定値軽減がある場合:

```text
最終ダメージ = max(基礎ダメージ, 最低保証ダメージ) * ダメージ倍率J - 固定値軽減
```

固定値軽減後に負数になった場合は、原則として0未満にしない。

```text
最終ダメージ = max(最終ダメージ, 0)
```

## ダメージ置き換え

一部の敵やギミックには、受けるダメージを特定値に置き換える効果がある。

例:

- 受けるダメージを1にする
- 一定回数だけダメージを0にする
- 特定条件下でダメージを別値に変換する

置き換え効果は個別仕様として管理し、通常の物理・術式に無理に混ぜない。

## 回避と被ダメージ無効化

回避と被ダメージ無効化は、成功するとダメージを0にする効果。

複数の回避・無効化効果は、それぞれ独立して判定される。

```text
成功率 = 1 - (1 - A) * (1 - B) * (1 - C) ...
```

ただし実装上は、確率だけを合成するより、効果の優先度と取得順を持ったリストとして処理する方が安全。

```text
1. 優先度が高い効果から判定
2. 同じ優先度なら取得順に判定
3. どれかが成功したらダメージは0
4. 以降の判定は行わない
```

注意:

- 物理回避は物理にのみ有効。
- 術回避は術にのみ有効。
- 物理・術回避は確定ダメージには基本的に無効。
- 種別指定のない被ダメージ無効化は、確定ダメージにも有効な場合がある。
- HP減少はダメージではないため、回避や無効化の対象外。

## シールド

シールドは、ダメージを1度だけ無効化する効果。

```text
シールドが有効なダメージを受ける
-> シールドを1つ消費
-> ダメージを0にする
```

注意:

- 指定されたダメージ種別にだけ有効なシールドがある。
- ダメージが発生したときだけ消費される。
- 回避や無効化で先にダメージが0になった場合、シールドは消費されない場合がある。

## バリア

バリアは、最終ダメージを受けた後にHPの代わりに削られる耐久値。

```text
if 最終ダメージ <= バリア耐久:
    バリア耐久 = バリア耐久 - 最終ダメージ
    HPダメージ = 0
else:
    HPダメージ = 最終ダメージ - バリア耐久
    バリア耐久 = 0
```

注意:

- バリアはダメージ計算後に処理する。
- 加護や被ダメージ軽減は、バリアの耐久値を実質的に増やすように働く。
- 属性限定バリアもある。
- 元素損傷専用バリアは、HPダメージ用バリアとは別に扱う。

## 命中率

命中率低下は、回避とは別の処理として扱う。

命中失敗:

- 攻撃そのものが失敗する。
- 被撃回復など「攻撃を受けた」処理が発生しない場合がある。

回避成功:

- 攻撃は届いているが、ダメージだけが無効化される。
- 被撃回復などが発生する場合がある。

## 攻撃速度と攻撃間隔

攻撃速度と攻撃間隔は別物。

```text
最終攻撃速度 = clamp(100 + 攻撃速度補正, 20, 600)
```

```text
最終攻撃間隔 =
  (基礎攻撃間隔 + 攻撃間隔固定補正)
  * (1 + 攻撃間隔割合補正)
  * 100 / 最終攻撃速度
```

アークナイツは 1秒 = 30フレームとして扱う。

```text
攻撃間隔フレーム = round_to_even(最終攻撃間隔 * 30)
実際の攻撃間隔 = 攻撃間隔フレーム / 30
```

注意:

- 攻撃間隔はフレーム単位に丸められる。
- 端数は累積しない。
- アニメーションや処理落ちで理論値とずれる場合がある。
- 一部攻撃は攻撃間隔が一定でない。

## DPSと総ダメージ

通常攻撃DPS:

```text
DPS = 1回あたりの最終ダメージ * 1回あたりのヒット数 / 実際の攻撃間隔
```

持続時間型スキル:

```text
攻撃回数 = floor(スキル持続時間 / 実際の攻撃間隔)
総ダメージ = 1回あたりの最終ダメージ * ヒット数 * 攻撃回数
```

弾薬型スキル:

```text
攻撃回数 = 弾薬数
総ダメージ = 1回あたりの最終ダメージ * ヒット数 * 弾薬数
```

単発型スキル:

```text
総ダメージ = 1回あたりの最終ダメージ * ヒット数
```

注意:

- 多段ヒットは、基本的に1ヒットごとに防御計算を行う。
- 物理多段攻撃は高防御に弱くなりやすい。
- 術多段攻撃は割合軽減なので、物理ほど多段による不利が出にくい。
- スキル発動モーション、初撃タイミング、攻撃範囲、対象数は別途扱う。

## 端数処理

ゲーム内部では小数を保持して計算する場面がある。

表示やフレーム変換では Unity の `Mathf.Round` 相当の偶数丸めが使われる。

```text
6.5 -> 6
7.5 -> 8
```

実装方針:

- 計算途中では、できるだけ小数を保持する。
- 表示用の整数変換は、計算ロジックから分離する。
- Python の `int()` は切り捨てなので、ゲーム内表示の丸めとは異なる。
- Python の `round()` は偶数丸めだが、浮動小数点誤差には注意する。

## コード上の推奨モデル

ダメージ種別はコード内では英語の固定文字列にする。

```text
physical
arts
true
elemental
elemental_impairment
hp_loss
healing
regeneration
```

UI表示では日本語に変換する。

| コード値 | UI表示 |
|---|---|
| `physical` | 物理 |
| `arts` | 術 |
| `true` | 確定 |
| `elemental` | 元素ダメージ |
| `elemental_impairment` | 元素損傷 |
| `hp_loss` | HP減少 |
| `healing` | 治療 |
| `regeneration` | 回復効果 |

最終的には、以下のようなデータを分けて持つと拡張しやすい。

| データ | 役割 |
|---|---|
| `AttackContext` | 攻撃側、スキル、倍率、ヒット数、攻撃種別 |
| `DefenseContext` | 防御側、防御力、術耐性、回避、バリア |
| `StatModifier` | A/B/C/D枠のステータス補正 |
| `DamageModifier` | 脆弱、加護、固定値軽減など |
| `DamageResult` | 計算後のダメージ、表示値、適用された補正 |

## 実装時の注意

- ダメージ計算と表示丸めは分ける。
- ステータス補正とダメージ補正を混ぜない。
- 「攻撃力+X%」と「攻撃力のX%のダメージ」を混同しない。
- 防御力無視・術耐性無視は、ステータス表示には反映されないダメージ計算時の補正として扱う。
- 最低保証は、ダメージ増減効果より前に比較する。
- 回避・無効化・シールド・バリアは、通常の基礎ダメージ式に混ぜず、後段の防御処理として扱う。
- 個別オペレーターの例外は、このファイルに直接増やしすぎず、スキル定義や個別ルール側で管理する。

## 追加検証が必要な領域

以下は最終版で扱う可能性があるが、実装前に個別検証した方がよい。

- 個別スキルの攻撃倍率がE枠か、ステータスバフか
- 攻撃対象ごとに変わる倍率
- 固定攻撃力で攻撃するスキル
- ダメージ置き換え効果
- バリアより後に処理される特殊効果
- 元素損傷の爆発効果中の再蓄積可否
- 攻撃間隔が一定でないスキル
- アニメーションによる攻撃間隔のズレ
